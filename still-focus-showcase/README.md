# Still — Focus Showcase

An interactive, responsive focus-app showcase inspired by the Still concept created in Framer.

**Live Framer reference:** https://best-centre-232873.framer.app/#still-preview

## Features
- Responsive desktop and mobile layout
- Sage, Sand, and Mist colour themes
- Working 25-minute focus timer with pause, resume, and reset
- Accessible focus-session information dialog
- Reduced-motion support

## Run locally
No build step is needed. Open `index.html` in a browser, or use a simple local server such as VS Code Live Server.

## Project structure
- `index.html` — page content and structure
- `css/styles.css` — responsive layout, visual styles, and theme variables
- `js/app.js` — theme switching, timer behavior, and information dialog

## Note
This is a standalone code implementation of the visual concept, not an export of the original Framer editor project.
